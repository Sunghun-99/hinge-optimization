# 1조 FEM 해석조건 / 재현 명세

## 1. 모델/범위

- 구조: 위아래 대칭의 타원형 홈을 갖는 2D flexure hinge
- 물리: 정적, 등방성, 선형탄성, 작은 변형, 평면응력(plane stress)
- 단위: mm, MPa (= N/mm²), 변위 mm, 반력 N/mm (면외 단위두께 기준)
- 3D 실제 폴더블 스마트폰의 상세 힌지 전체를 모사한 모델이 아님.

## 2. 형상

- 외곽 길이 `L = 12 mm` 고정
- 홈 수평 반장축 `a = 2.0, 2.5, 3.0, 3.5, 4.0 mm` (5수준)
- 홈 깊이 `b = 1.0 ~ 2.0 mm`, 0.1 mm 간격 (11수준)
- 중앙 최소 두께 `t = 0.5 ~ 1.0 mm`, 0.1 mm 간격 (6수준)
- 외곽 높이 `H = 2b + t` (따라서 설계별 외곽 높이는 **고정되지 않음**)
- 중심 x좌표 `L/2`, 위·아래 동일한 반타원 홈을 Gmsh spline으로 근사
- 컷아웃 끝단의 별도 필렛(반경 0.1 mm 등)은 구현되지 않음
- 모든 330개 설계의 (a, b, t) 조합을 한 번씩 계산

**주의:** `H=2b+t`, 길이 12 mm, 컷아웃 경계 접합 규칙은 제안서에 수치로 지정되지 않은 **팀 자체 모델링 가정**이다. 현재 결과 분석에서 b의 변화는 외곽 높이 변화까지 함께 포함한다.

## 3. 물성·변위

- 재료 해석상 명칭: Steel (등방성 선형탄성 모델)
- 탄성계수 `E=209000 MPa`, 포아송비 `nu=0.29`
- 시험 변위 `delta=0.01 mm`
- 왼쪽 끝단: `ux=uy=0`
- 오른쪽 끝단: `uy=+0.01 mm`, `ux`는 자유
- 홈 경계 및 그 밖의 변위 비지정 표면: 자연 경계조건(traction free)
- 면외 기준두께: 1 mm; 2D 반력 결과는 폭 1 mm 기준 N/mm로 보고함
- 명목 항복강도 355 MPa 및 안전율 1.5를 **자체 기준으로 설정**, 명목 허용응력 236.667 MPa
- 위 물성 및 하중은 현재 단순화 모델에 적용한 선택값이며, 실제 제품의 공개 설계사양이 아님

## 4. 수치해석

- 메시: Gmsh 2D 1차 삼각형 요소, 홈 주변 세분화
- 기하: `warp.fem.Trimesh2D`
- 강성행렬 조립: NVIDIA Warp 1.16.0 `warp.fem`, 2D 선형탄성 평면응력 약식
- 강성행렬 변환 및 구속 자유도 해법: SciPy sparse `spsolve`
- 응력: 요소별 P1(상수 변형률) 응력으로 계산한 von Mises 응력
- 학습타깃: 모든 요소의 von Mises 응력 중 최대값 `sigma_max_MPa`
- 보조 출력: 99백분위 응력, 우측 반력, 요소/절점 수, 자유도 잔차, 런타임
- 배치 전체 `mesh_factor=1.0`, device=`cpu`

## 5. 원본 파일에 기록된 실제 환경

- Python 3.12.10
- Warp 1.16.0
- Gmsh 4.15.2
- SciPy 1.18.1
- Device CPU (데이터를 생성한 PC의 NVIDIA CUDA 드라이버 이용 불가)

## 6. 재현 명령

Windows PowerShell, 프로젝트 폴더 안의 `hinge_fem.py` 기준:

```powershell
python hinge_fem.py --batch --E 209000 --nu 0.29 --delta 0.01 --L 12 --device cpu --out outputs_final
```

`hinge_fem.py`의 `--batch`는 5×11×6의 격자를 생성한다. 기존 결과파일이 동일 폴더에 있으면 일부 조합을 건너뛰므로 조건을 바꾸거나 재해석할 때는 다른 `--out` 경로를 사용할 것.

## 7. 가정과 검증의 구분

- **확인된 사실:** 330개 고정 조합의 해석이 예외 없이 완료됐고, 기록된 수치해가 유한하며, 일부 대표 조건에서 메시 수렴 결과를 확보했다.
- **아직 확인되지 않은 사항:** 330개 전체 형상의 메시 수렴, 홈 끝단 필렛 민감도, 실험 대비 물리적 타당성, 실제 스마트폰 힌지 성능 재현.
- **최적화 관련 주의:** 단순 응력 제한 및 최소 두께 목적함수에서는 현재 데이터 전부가 허용응력 이내이고, t가 증가할수록 응력이 증가하는 경향이 있어 문제가 사실상 자명해진다.
